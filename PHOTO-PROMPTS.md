# Photo prompts

Prompts for AI-generated product photos (ChatGPT, Gemini, Midjourney, etc.). Each garment needs three photos of the **same** piece: front, back and side.

**Have a photo of the real clothes?** Use the generic prompt at the top of the admin panel instead: attach the photo, paste the prompt, and it makes all three. The prompts below describe each product from scratch, for when there's no photo.

## How to use them

1. **Front first.** Paste the product's front prompt into a new chat and generate.
2. **Back and side in the same chat, with the front photo attached.** This keeps the same garment, colours and lighting. If the tool doesn't let you attach images, say "same garment as the previous image".
3. **Check that the three match** (colour, fabric, logo position). If one doesn't, generate it again.
4. **Add them in the admin panel.** Run `pnpm dev`, click **Admin** in the store header, drop each photo into the product's Front, Back or Side box, and press **Save**. The background is removed and the photo is sized and placed for you. If a side photo has the front facing left, press **Mirror** before saving.

Tip: start with 2 or 3 products to test, then do the rest.

---

## Shared parts

Every prompt ends with this. It's already included in each prompt below; it's only here so you know what it does.

> Ghost-mannequin style: the garment keeps its natural shape with no person, no mannequin, no hanger and no hook in view. Plain seamless solid-colour background, soft even studio lighting, natural soft fabric folds, realistic fabric texture, sharp focus, no props, no extra text. Portrait 4:5.
